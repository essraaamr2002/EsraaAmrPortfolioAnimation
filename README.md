# Animated Developer Portfolio

A personal portfolio built with Next.js, React and TypeScript, exploring interactive presentation and animation.

## Technology
Next.js 14, React 18, TypeScript, Tailwind CSS, Framer Motion, Three.js, React Three Fiber and Drei. The project also includes the Supabase client dependency.

## What to review
Component design, motion, interactive presentation and responsive styles.

## Run locally
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
npm run start
```

**Note:** The listed packages are verified from the dependency manifest; this README does not claim that every dependency is used in a deployed feature.
